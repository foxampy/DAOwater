# 🌍 1. Глобальные и транснациональные API

## 🌐 **USGS Water Data API (США — крупнейшая открытая сеть мониторинга)**

Набор API от **U.S. Geological Survey (USGS)** с широким спектром гидрологических данных:

### 📊 Основные категории

* **Continuous Values API** — данные в реальном времени (поток, уровень, параметры).
* **Daily Values API** — ежедневные значения гидрологии (исторические).
* **Monitoring Locations API** — metadata по станциям: координаты, типы датчиков.
* **Time Series Metadata API** — данные о временных рядах.
* **Water Quality Portal (WQP) APIs** — данные качества воды (USGS + EPA + локальные агентства).
* **USGS Water Samples API** — прямой доступ к наблюдениям качества воды.
* **Real-Time Flood Impacts API** — данные о потенциальных зонах наводнений.
* **National Imagery / NIMS** — гидрологические изображения, модели и визуализация.
  🔗 Документация по API и доступ: [https://api.waterdata.usgs.gov/](https://api.waterdata.usgs.gov/) ([api.waterdata.usgs.gov][1])

### 📌 Применение

* Интеграция показателей уровня рек и озёр
* Мониторинг качества воды по параметрам (температура, загрязнение)
* Исторические тренды
* Flood/risk данные

---

## 🚀 **NASA Earthdata / STREAM API (глобальные спутниковые данные)**

API предоставляет доступ к спутниковым картам качества воды, основанным на **Landsat и Sentinel-2**, с обновлением до **≈ <6 часов**.
🔗 Сервис: NASA Earthdata STREAM — интерактивное API для обработки водных данных в near-real-time ([NASA Earthdata][2])

### 📌 Применение

* глобальные неопосредованные индикаторы качества воды
* вода/экология/смеси (спутниковые данные)
* фильтрация по временным/пространственным параметрам

> Примечание: для доступа требуется Earthdata Login.

---

## ☀️ **NASA OpenET API (этвапотранспирация — ключ для расчётов баланса воды)**

API даёт данные о **эвапотранспирации (ET)** — важный параметр водного баланса, влияющий на водопользование, сельское хозяйство и устойчивость ресурсов.
🔗 OpenET API — бесплатный API от NASA для интеграции данных ET в сторонние системы ([NASA][3])

### 📌 Применение

* оценка потерь воды
* баланс водных систем
* использование в моделировании устойчивости

---

# 🛰️ 2. Региональные API

## 🇷🇺 **Росводресурсы — Водные данные API**

Российская цифровая платформа «Водные данные» предоставляет открытые данные о водохозяйственной ситуации в России через API и интерактивные данные.
🔗 Платформа содержит инструкции для запросов API в режиме реального времени к государственному водному реестру и мониторингу ([voda.gov.ru][4])

### 📌 Применение

* мониторинг локальных/региональных водных объектов РФ
* интеграция с геоинформационными панелями
* статистика и паспорта объектов

## 🌍 Дополнительные региональные/национальные API (примеры)

*(уточнять вручную после списка, но эти источники часто имеют API/доступ к данным)*

* **AquaInsight / AquaMap KZ** — региональные данные качества и экологические индексы водных объектов (Казахстан). ([aquainsightmap.com][5])
  *скорее всего, API доступен на основе платформы (нужны уточнения через контакты/документацию)*

# 📈 3. Другие полезные API и данные

## 📌 EOSDIS / Earthdata Search (NASA) — глобальный каталог данных

Это не API данных напрямую, но *API поиска и метаданных*, который позволяет находить, запрашивать и интегрировать множество дочерних источников данных NASA о Земле, включая спутниковые наблюдения за водными системами. ([Википедия][6])

## 💧 NHGF / Hydrology API (USGS National Hydrologic Geospatial Fabric)

Сервис предоставляет доступ к пространственным данным гидрологии (географические сети рек, бассейны, границы водосборов). ([api.water.usgs.gov][7])

---

# 📌 4. API для связанных параметров, расширяющих контекст

Эти API не о воде напрямую, но **значимо для анализа экосистем, изменений климата, индикаторов качества и рисков**:

* **QAICN API (AQI данные качества воздуха, включают индикаторы смежного воздействия на водные экосистемы)** — API качества воздуха с зайцем API-ключом (для сопоставления с экологическими показателями) ([aqicn.org][8])
  *(частично связанно, но может быть полезно для взаимосвязанных индексных панелей)*

* **Метеорологические открытые данные (например, Росгидромет EIP)** — включает данные об авариях и загрязнении окружающей среды, аэрологических данных, косвенно коррелирующих с водным состоянием ([eip.meteo.ru][9])

# 🧠 5. API структурированные по категориям данных

| Категория                             | Примеры API                         | Данные                           |
| ------------------------------------- | ----------------------------------- | -------------------------------- |
| **Гидрология (реальное время)**       | USGS Continuous Values OGC API      | уровень воды, поток, параметры   |
| **Гидрология (исторические)**         | USGS Daily Values                   | значения за сутки                |
| **Качество воды**                     | Water Quality Portal / USGS Samples | химия, показатели качества       |
| **Спутниковые данные**                | NASA STREAM API, OpenET             | вода, растительность, ET         |
| **Гидросеть/пространственные данные** | NHGF / NLDI API                     | география рек, водосборов        |
| **Региональные платформы**            | Росводресурсы API                   | локальные гидрологические данные |
| **Экология и климат**                 | NASA Earthdata Search               | косвенно связанные параметры     |
| **Смежные среды**                     | API качества воздуха                | вспомогательные индексы          |

# 📌 6. Что ещё учесть при интеграции

✔ Реестр API может требовать API-ключи (например, USGS OGC API). ([api.waterdata.usgs.gov][10])
✔ Спутниковые сервисы дают **глобальные данные**, но могут требовать авторизацию (Earthdata Login). ([NASA Earthdata][2])
✔ Для многих API существуют SDK / готовые клиенты (R, Python), которые облегчают интеграцию. ([doi-usgs.github.io][11])
